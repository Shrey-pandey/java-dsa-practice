# Maximum Element in an Array

## Problem
Find the **maximum element** present in a given array.

Example:
```
Input:  [3, 7, 2, 9, 5]
Output: 9
```

---

## Key Idea
Traverse the array and keep track of the **largest element found so far**.

Steps:
- Initialize `max` with the first element.
- Compare each element with `max`.
- If a larger element is found, update `max`.

---

## Complexity

**Time Complexity:** `O(n)`  
**Space Complexity:** `O(1)`

---

## Concepts Used
- Array Traversal
- Comparison
- Linear Search
